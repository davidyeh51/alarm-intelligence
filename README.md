# 告警洞察平台
以 Supabase Auth 與受 RLS 保護的資料表呈現歷史告警快照，提供查詢、篩選、CSV 匯出及統計分析。

資料來自原監控系統歷史告警，每次匯入保存快照；自動排程預設關閉，需完成憑證設定及明確啟用；事件數依原系統以案場、設備及原始告警類型分組；每組影響筆數為底層明細數。分組事件數並不代表故障時長或獨立事故數。新網站登入獨立於原網站。

以任意靜態 HTTP 伺服器或 GitHub Pages 發佈。前端只含 Supabase 可公開的 publishable key；讀取權限由登入及資料庫授權名單控制。請勿加入來源密碼、Supabase secret/service_role key 或告警資料檔。

第 03 頁依原始「無發電數據」及可辨識 INV 編號彙整案場；不包含無設備編號的全場告警。缺少發電數據不等於已確認停發，以頁面上方最後成功匯入時間判斷資料新鮮度。

待追蹤事件以案場為單位；重複匯入更新既有事件，僅人工確認後結案。來源缺失不代表已修復。
